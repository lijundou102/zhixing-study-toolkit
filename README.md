# 知行 · 个人学习工具箱

> 在线访问：<https://lijundou102.github.io/zhixing-study-toolkit/>

一个面向大学生的轻量学习管理网站，使用原生 HTML、CSS 和 JavaScript 开发，无后端、无数据库服务器。项目把「任务规划、专注计时、网站收藏、资料整理」集中在一个页面里，帮助使用者更有序地安排学习。

## 项目简介

学生在日常学习中常常需要在多个工具之间切换：记录待办任务、用计时器保持专注、收藏学习网站、保存学习资料。本项目把这些高频需求整合到一个单页网站中，旨在：

- 通过任务管理梳理学习计划；
- 通过专注计时器安排专注与休息时间；
- 通过推荐网站管理收藏常用学习网站；
- 通过「我的学习资料」把学习文件保存在当前浏览器中，随时查看、下载。

本项目是一个课程作业性质的前端项目，功能以本地使用为主，不具备账号系统、云同步或跨设备同步能力。

## 主要功能

### 首页仪表盘

- 展示任务总数、已完成数量和完成百分比，进度用**圆环**表示；
- 提供待办任务预览（最多显示 4 条未完成任务）；
- 提供「新建任务」「开启专注」「浏览学习资源」等快捷入口；
- 提供学习资源推荐（每个分类各取一条）；
- 桌面端采用左右分栏布局，平板和手机端自动切换为单列。

### 任务管理

- 新增、完成、取消完成和删除任务；
- 按「全部 / 待完成 / 已完成」筛选；
- 任务数据保存在浏览器 `localStorage` 中，刷新后自动恢复；
- 输入为空时不会添加任务。

### 专注计时器

- 专注与休息两种模式；
- 开始、暂停、继续、重置；
- 自定义专注和休息时长：
  - 专注时长范围 **1–180 分钟**（默认 25 分钟）；
  - 休息时长范围 **1–60 分钟**（默认 5 分钟）；
  - 仅接受范围内的整数，空值、小数、0、负数或超范围会被拒绝；
- 自定义时长保存在浏览器中，刷新后恢复；
- 倒计时结束后显示完成提示；
- 注意：正在进行的倒计时**不会**跨刷新恢复，刷新后回到当前模式的完整时长。

### 推荐网站管理

- 首次使用时内置 9 条推荐网站；
- 添加、删除网站；
- 按网站名称搜索（不区分英文大小写、忽略空格）；
- 按分类筛选，支持「数学 / 编程 / 英语 / 其他」（「全部分类」仅用于筛选，不保存为实际分类）；
- 在卡片上快捷修改网站分类；
- 网站列表保存在浏览器 `localStorage` 中，刷新后恢复。

### 我的学习资料

- 通过文件选择器一次上传一个或多个学习文件；
- 使用浏览器 `IndexedDB` 保存文件本体及元数据；
- 按文件名搜索（不区分英文大小写）；
- 按分类筛选（数学 / 编程 / 英语 / 其他），上传时可选择分类（默认「其他」）；
- 支持 PDF 与图片（png / jpg / jpeg / webp / gif）在站内预览；
- 支持文件下载和删除；
- 文件类型与单文件大小校验：
  - 允许格式：`pdf`、`doc`、`docx`、`ppt`、`pptx`、`xls`、`xlsx`、`txt`、`md`、`png`、`jpg`、`jpeg`、`webp`、`gif`；
  - 单文件最大 **20 MB**；
- 上传成功 / 失败、空列表等都有明确的提示。

> 说明：Word、PowerPoint、Excel 和文本文件在本站**仅提供下载**，不做站内解析预览。

## 技术栈

| 技术 | 用途 |
|------|------|
| HTML5 | 页面结构与内容组织 |
| CSS3 | 页面主题样式、布局与响应式设计 |
| 原生 JavaScript | 任务管理、搜索筛选、计时器、文件管理、页面交互等全部逻辑 |
| localStorage | 保存任务、计时器配置、推荐网站列表等文本数据 |
| IndexedDB | 保存「我的学习资料」中的文件本体及相关元数据 |

本项目**未使用**任何前端框架、第三方 UI 库、后端框架、数据库服务器或云服务。

> 说明：本地运行时可能使用 `python3 -m http.server` 启动一个**静态文件服务器**，它只负责把静态文件提供给浏览器，**并不构成 Python 后端**。

## 本地运行方法

项目使用 IndexedDB 保存学习资料，推荐通过本地 HTTP 服务器运行，而不是直接双击 `file://` 打开。

macOS 步骤：

1. 打开「终端」（Terminal）；
2. 进入项目目录，例如：
   ```bash
   cd /path/to/项目目录
   ```
3. 启动静态服务器：
   ```bash
   python3 -m http.server 8000
   ```
4. 在浏览器打开：<http://localhost:8000/>
5. 使用完毕后，在终端按 `Ctrl + C` 停止服务器。

注意：

- 服务器启动后，**需要保持该终端窗口一直运行**，关闭终端即停止服务；
- 如果 8000 端口被占用，可换用其他端口，例如 `python3 -m http.server 8080`，然后访问 `http://localhost:8080/`。

其他操作系统：只要安装了 Python 3，同样可在项目目录执行 `python3 -m http.server 8000`。

## 数据保存方式与限制

- 任务、计时器设置、推荐网站列表通过 `localStorage` 保存，属于**当前浏览器的当前来源（origin）**。使用的键分别为：
  - `zhixing-tasks`：任务列表；
  - `studyCompanionTimerSettings`：计时器时长设置；
  - `zhixing-websites`：推荐网站列表。
- 「我的学习资料」通过 `IndexedDB` 保存（数据库名 `zhixing-study-materials`），同样属于**当前浏览器的当前来源**。
- 备份项目文件夹**不会**自动包含浏览器中保存的任务、网站收藏、计时器设置或上传的学习资料。
- 从 `file://` 切换到 `http://localhost:8000`，或更换域名、端口、设备后，本地数据通常**不会自动迁移**。
- 清除浏览器的网站数据或存储，可能导致本地保存的资料丢失。
- 当前版本**不具备**自动云同步、跨设备同步或数据迁移功能。
